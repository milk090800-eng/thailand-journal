Getting around交通方式

曼谷市區
  • 嘟嘟車用 Nuvim 叫車 APP，公定價，掃 QR code
  • BTS 一日票 150 元，可在 KKday 購買
  • 兔子卡可刷：BTS 綠線、MRT 黃線與粉紅線、BRT 公車、昭披耶船
  • Grab／Bolt：機場與尖峰方便，活動夜晚會塞車
機場與城際
  • 機場快線 ARL：B1，約 45 泰銖，05:30–24:00，到 Phaya Thai 約 26–30 分
  • 曼谷 → 芭達雅：Ekkamai 東部巴士總站，2–2.5 小時，130–160 泰銖
  • 芭達雅 → 機場：North Pattaya Bus Terminal 135 泰銖／人；計程車約 1,500 泰銖

VAT Refund退稅小幫手

條件
  1. 在貼有「VAT REFUND」的店家購物
  2. 單店單日滿 2,000 泰銖
  3. 旅程總消費達 5,000 泰銖／人
  4. 單價超過 2 萬泰銖的商品，先到機場外海關辦公室蓋章（4F 大廳 W 排報到櫃檯附近）
流程
  1. 購物後向店家索取退稅單＋發票
  2. 報到前帶商品到海關辦公室蓋章
  3. 高價品可隨身攜帶，避免查驗不過
  4. 過安檢後到 VAT REFUND 櫃檯領取（會檢查物品）
